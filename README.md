# 碎碎念念 · 一座会长纸鹤的粉雾展塔

一间可以走进去的 3D 私人展塔：**四层环形中庭，一层一个主题**，中庭头顶是**一整片流动的粉雾海**，天花上一圈暖粉灯带，**十几只粉纸鹤绕着中庭慢慢盘旋、一边扇翅膀**。一层展厅**正中央立着一台老电视**（柜子上有一张笑脸），屏幕上是那张照片，左边三张、右边三张照片绕着它排开；电视里能点三首真歌（默认 Stay With Me），点「一起听听」下面会显示播放状态，**电视旁边的小白和四只小动物会跟着音乐一起蹦**。整体配色是粉调。

照片全部单排挂在每层的环形展墙上，**顶边对齐同一条线**，从下往上像被一根线串起来。**「花与光」重新吊回塔顶**：外圈 5 张、内圈 4 张，用细钢索吊在天花下，脸朝中庭中心；中庭上空另外只有粉色气球和千纸鹤，二层那截横跨中庭的**空中曲桥已撤掉**。

| 2F | 02 天空的自由 | 13 |
| 3F | 03 生活碎片 | 10 |

共 35 件，都在墙上。

旋梯错开方位贴着外墙盘旋而上；第三层的梯子已按需求撤掉。每层的拱形天光窗**自动避开照片**（布展完再挂窗，撞到画就往旁边让），所以不会出现窗户压住作品的情况。楼层护栏是**玫瑰金扶手 + 磨砂玻璃挡板 + 一圈小灯珠**。

顶部导航的「**展信佳**」是一封写给你的信（标题「相信就会存在」，日期 2026 · 11 · 28），右侧立着一座**大沙漏**：从 **2025.12.07** 起算，沙漏按「今天还剩多少」慢慢漏，每天午夜翻一次身。计时器下方那句是「2025年12月7日初相识 少年的内中自此展开了一片粉雾海」。

## 怎么打开

双击根目录的 **`启动展馆.bat`**，会自动起本地服务并打开浏览器（http://127.0.0.1:8123/）。

想手动启动也可以：

```bash
# 任选其一
python -m http.server 8123 --bind 127.0.0.1 --directory site
node server.js 8123
```

> 必须通过本地服务器打开，直接双击 `site/index.html`（file://）会因为浏览器安全策略导致模块和图片加载失败。

## 想放到网上（GitHub Pages）

站点是纯静态的，直接托管在 GitHub Pages 就行，免费 + HTTPS。完整步骤（网页上传 / 命令行 / Actions 三种方式、自定义域名、版权注意）都在 **`部署到GitHub.md`** 里；工作流文件已经准备好了：`.github/workflows/deploy.yml`（发布 `site/` 目录），`site/.nojekyll` 也在。

## 想改内容

- **章节顺序、标题、文案、那封信**：编辑 `site/js/data.js`（`CHAPTERS` 数组顺序 = 观展顺序，`PROFILE` 是「展信佳」的正文与落款，`paragraphs` 一行一段）。
- **沙漏起点**：`site/js/main.js` 顶部的 `SINCE = new Date('2025-12-07T00:00:00+08:00')`，改成别的日期即可；沙漏的造型在 `buildAbout()` 里的那段 SVG（`#hgSvg`），配色在 `style.css` 的 `.hg-card / .hg-svg`。
- **粉雾海天花与星星**：`museum.js` 的 `ceilTex/underTex`（粉雾渐变）、`mistLayers`（飘动雾层）、`ceilStars`（星点）；顶部纸鹤在 `buildCranes()`，小灯带在 `buildCeilingLights()`，都在 `layout` 上挂着，主循环里 `main.js` 驱动。
- **小白**：`buildDog()`，位置 `g.position.set(-3.5, 0, -3.2)`（站在电视右边、留一小段距离，不动位置，只转头看人）。四只跳舞的小动物在 `buildPartyAnimals()` 的 `spots` 里，站位在电视左前方。
- **电视旁边的小动物**：`buildPartyAnimals()`，四只（奶白兔 / 粉熊 / 小黄鸡 / 薄荷兔）。音乐一响 `layout.dancers` 里的 `userData.hop.amp` 会被主循环推到 1，它们就一起上下蹦、甩手；暂停后慢慢停下。
- **换歌 / 真音乐**：把三首歌的 mp3 放进 `site/assets/audio/`，文件名对应 `data.js` 里 `SONGS` 的 `file` 字段：
  ```
  site/assets/audio/stay-with-me.mp3     ← 鬼怪《Stay With Me》（默认播放）
  site/assets/audio/fenwu-hai.mp3        ← 易烊千玺《粉雾海》
  site/assets/audio/baby-dont-cry.mp3    ← 《Baby, Don't Cry（인어의 눈물 / 人鱼之泪）》
  ```
  播放器每首歌都会先 `fetch` 找这个文件，找到就放真歌（循环、走同一个频谱可视化）；找不到才退回内置的「八音盒钢琴」合成版。**这三首是商业版权歌曲，别把仓库设成公开**（见 `部署到GitHub.md` 的注意事项）。
- **中庭短片**：已取消（原来的循环银幕整段删掉了），中庭现在是干净的环形展厅。
- **电视的位置与大小**：电视立在**一楼展厅正中央**的地面上，屏幕朝入口方向，一层的六张照片分成**左边三张、右边三张**，绕着它排在弧墙上。想改位置改 `buildTV()` 里的 `TV_AT_CENTER` 分支（`TV_POS` + `rotY`）；想改大小改 `TV_S`（现为 1.22）；左右分组的间距在布展循环里的 `tvHalf`（现为 `3.4 / DIM.R`）；柜子上的笑脸在 `buildTV()` 里「柜子正面的一张笑脸」那一段（现在只留两只眯眼，嘴线与把手已去掉）。
- **电视屏那张图**：`site/assets/site/tv-photo.jpg`（这张壁纸没动过）；它在 `buildTV()` 里用 `<img>` + canvas 贴到屏幕上并旋转 180°，不依赖贴图队列，改成别的图只要替换文件。
- - **换照片**：把新图放进 `D:\合集\<分类>\`，然后在本目录执行
  `python tools/manifest.py`（会重新生成 `site/assets/web/` 和 `site/js/manifest.json`）。
  或者直接把图片按 `pink-01.jpg`、`sky-03.jpg` 这样命名放进 `site/assets/web/<分类>/`，并同步改 `site/js/manifest.json` 里的宽高。
- **照片是横躺的**：`tools/manifest.py` 顶部的 `ROTATE` 表可以单独摆正某张图，键是输出文件名：
  ```python
  ROTATE = {
      "dusk-05": 90,   # 逆时针转 90°（照片原本横躺着时用）
      # "daily-03": 270, # 顺时针转 90°
      # "sky-02": 180,   # 上下颠倒
  }
  ```
  改完再跑一次 `python tools/manifest.py`，宽度高度会自动写进清单，墙上会自动重排。
- **灯光/建筑尺寸**：`site/js/museum.js` 顶部的 `DIM`（半径、层高、天窗大小）与 `setupLights()`。
- **主题色**：`site/css/style.css` 顶部 `:root` 的 `--ink / --green / --rose`（`--green` 这个名字是历史遗留，现在就是主强调色），以及 `site/js/museum.js` 里的 `MAT`（墙面、地面、画框）和 `setupLights()` 的灯色。想把粉色再压深一点，把 `MAT.wall` 从 `0xfcf2f1` 调到 `0xf9e9e9` 即可。
- **楼层识别**：`site/js/main.js` 里按镜头高度算楼层（`round((y - 1.7) / DIM.LH)` 即当前章节），半径 `r >= 18` 才算进了展厅，站在中庭中间仍是「00 云上中庭」。左文案下方的 `1F…5F` 徽标和底部章节条的楼层分隔都读同一个来源。
- **章节机位**：`museum.js` 里 `layout.chapters[...]` 的 `view`（站哪）/ `lookAt`（看哪），目前是「站在环廊上沿弧墙斜看整列」；孤品楼层会自动走近、正对着看。
- **楼层分区**：`site/js/museum.js` 里 `buildMuseum` 的 `LEVELS` 数组 = 从下往上的楼层主题，顺序与 `data.js` 的 `CHAPTERS` 一致，改一行就换楼：
  ```js
  const LEVELS = ['pink', 'sky', 'daily', 'dusk']; // 1F→4F
  ```
  层高、层数、天窗半径在文件顶部 `DIM`：`LH: 4.9`（层高）、`N: 4`（层数，改这里会自动加/减楼板、旋梯、楼层灯与楼层徽标）。旋梯每一段的起始方位角在 `stairBase` 数组里。

## 结构

```
启动展馆.bat          ← 双击启动
server.js             ← 无依赖静态服务器（Node 兜底）
site/
  index.html
  css/style.css       ← 全部界面样式
  js/data.js          ← 展馆内容配置（改这里）
  js/museum.js        ← 建筑、布展、灯光（Three.js 程序化生成）
  js/controls.js      ← 镜头控制：方向键 / 拖拽 / 滚轮 / 自动导览
  js/main.js          ← 启动、贴图加载、拾取、界面联动
  js/manifest.json    ← 照片清单
  assets/web/         ← 压缩后的展品图（4.4MB，原 185MB）
  vendor/three.module.js  ← 本地 Three.js r160，无外网依赖
tools/                ← 图片压缩与截图/交互自测脚本（可选）
```

## 说明

- 完全离线可用：Three.js 已放在 `vendor/`，不请求任何 CDN 或字体。
- 首屏是一张「嗨，好久不见。」的开幕页，图片 8 路并发解码，进度到 84% 左右即进入展馆，剩余照片会自动补上。
- 性能：贴图并发 8 路、渲染分辨率上限 1.5 倍（`renderer.setPixelRatio`）、阴影贴图 1024。若你的机器仍觉得卡，把 DPR 上限调到 1，或在 `museum.js` 里关闭 `renderer.shadowMap`。
- 「展信佳」里是写给你的那封信，右边是沙漏（信纸过长时左栏可单独滚动）。
